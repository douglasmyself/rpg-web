# ⚔️ O Sobrevivente - RPG Web & Python

> Um jogo de RPG baseado em turnos desenvolvido inicialmente em Python e adaptado para uma aplicação Web interativa. Projeto criado como parte do portfólio prático para o curso de **Licenciatura em Computação** na **Universidade Estácio de Sá**.

---

## 🚀 Sobre o Projeto
**O Sobrevivente** é uma aventura em masmorras onde o jogador assume o papel de um herói enfrentando oponentes em salas consecutivas. O projeto demonstra conceitos fundamentais de programação, como Programação Orientada a Objetos (POO), controle de turnos, lógica de combate e desenvolvimento Front-End.

## 🕹️ Funcionalidades
* **Escolha de Classes**: Selecione entre **Guerreiro** (maior quantidade de vida) ou **Mago** (ataque mais forte).
* **Sistema de Batalha em Turnos**: Ataque os inimigos ou utilize **Kits Médicos** estratégicos para recuperar a vida durante o perigo.
* **Progressão de Inimigos**: Enfrente o *Ladrão*, o *Trapaceiro* e o temido chefe *Dragão das Sombras*.
* **Interface Web Moderna**: Versão jogável direto no navegador com um design limpo e responsivo em *Dark Mode*.

---

## 🛠️ Tecnologias Utilizadas
* **Python** (Lógica principal, estruturas de dados e classes)
* **HTML5 & CSS3** (Estrutura visual e estilização moderna)
* **JavaScript** (Manipulação do DOM e regras de combate no navegador)
* **GitHub Pages** (Hospedagem e deploy contínuo)
